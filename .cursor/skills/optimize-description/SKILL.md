# 優化鉤針作品文案

分析並優化現有作品的文案描述，提供更有溫度、更有感染力的版本。

## When to Use

- 當用戶說「優化文案」、「優化專案 #N」時
- 當用戶說「improve description」、「重寫描述」時
- 當用戶覺得現有描述不夠有感染力時
- 當用戶想要統一調整所有作品的文案風格時

## Instructions

### 步驟 1: 讀取專案資料

1. 讀取 `data/project.ts`
2. 找到用戶指定的專案（透過 ID 或名稱）
3. 如果沒指定，詢問要優化哪個專案

### 步驟 2: 分析現有描述

評估以下面向：
- 情感表達程度（1-5 分）
- 畫面感和使用情境（1-5 分）
- 三語風格一致性（1-5 分）
- 關鍵字運用（1-5 分）

### 步驟 3: 根據風格要求重寫

提供三種風格選項：

**🌸 溫暖風格**（預設）

繁體中文：
- 使用「溫柔」「舒心」「療癒」「陪伴」等詞彙
- 描繪使用情境和感受
- 強調手作的溫度

英文：
- 使用 cozy, comforting, heartwarming, tender
- Paint usage scenarios
- Emphasize handcrafted warmth

日文：
- 使用「優しい」「心地よい」「癒し」「寄り添う」
- 使用情境を描写する
- 手作りの温もりを強調

---

**✨ 優雅風格**

繁體中文：
- 使用「細膩」「雅緻」「品味」「精緻」等詞彙
- 強調工藝和質感
- 突出獨特性

英文：
- 使用 elegant, refined, exquisite, sophisticated
- Emphasize craftsmanship
- Highlight uniqueness

日文：
- 使用「上品」「繊細」「優雅」「洗練された」
- 職人技を強調
- 特別感を表現

---

**🎀 活潑風格**

繁體中文：
- 使用「可愛」「俏皮」「繽紛」「活力」等詞彙
- 營造輕鬆愉快的氛圍
- 適合年輕族群

英文：
- 使用 playful, vibrant, cheerful, lively
- Create fun and joyful vibes
- Appeal to younger audience

日文：
- 使用「可愛い」「元気」「楽しい」「明るい」
- 楽しい雰囲気を作る
- 若い世代にアピール

### 步驟 4: 顯示對比

以並排方式顯示：

```
【原始版本】
繁中：...
英文：...
日文：...

【優化版本】（溫暖風格）
繁中：...
英文：...
日文：...
```

### 步驟 5: 詢問並套用

提供選項：
1. ✅ 套用並部署
2. 📝 僅套用不部署
3. 🔄 換一種風格重新生成
4. ❌ 取消

## 範例對話

**用戶**：優化專案 #3 的文案，要更溫暖一點

**AI**：好的，讓我看看專案 #3（花朵髮帶）...

**現有描述分析**：
- 情感表達：3/5
- 畫面感：3/5
- 風格一致性：4/5

**原始版本**：
> 立體花朵造型髮帶，粉紫與灰藍的溫柔配色，為日常增添優雅氣息。

**優化版本**（溫暖風格）：
> 每一朵立體小花都像是春天的私語，粉紫與灰藍交織出最溫柔的午後時光。戴上它，就像被柔軟的雲朵輕輕擁抱，讓日常的每個瞬間都染上一抹療癒的色彩。

要套用這個版本嗎？

## 批次優化

如果用戶說「優化所有作品」：

1. 列出所有專案的描述評分
2. 建議優先優化低分項目
3. 逐一進行優化
4. 最後一次性部署

## 注意事項

- 保持事實準確性（顏色、材質等不要改動）
- 三種語言風格要一致
- 優化後的字數應該在建議範圍內
- 更新前先顯示預覽
