# 新增勾針作品 - AI 提示詞模板

## 🎯 基本提示詞（推薦使用）

```
請幫我分析這個勾針作品並新增到網站。

圖片已上傳。

請提供：
1. 多語言標題（繁中、英文、日文）
2. 作品分類
3. 材質建議
4. 製作時間估計
5. 詳細描述（溫暖、有情感的風格）
6. 配色 Hex 代碼

確認後請更新 data/project.ts 並準備部署。
```

## 🎨 詳細版提示詞（需要更多控制時使用）

```
我有一個新的勾針作品需要新增到網站。

【作品類型】：（如：髮帶 / 耳機包 / 杯墊等）
【主要配色】：（如：粉紅色、藍色等）
【特殊工藝】：（如：蕾絲編織、祖母方格等）
【目標受眾】：（如：日常使用 / 送禮 / 收藏）

請根據上傳的圖片和以上資訊：

1. **分析圖片**
   - 識別編織技法
   - 提取精確的配色（Hex 代碼）
   - 判斷作品特色

2. **生成內容**（JSON 格式）
   - title: 三語標題
   - category: 三語分類
   - materials: 材質描述
   - timeSpent: 製作時間
   - description: 詳細描述（繁中：溫暖細膩，英文：簡潔優雅，日文：可愛柔和）
   - colorPalette: Hex 代碼陣列

3. **寫作風格要求**
   - 繁體中文：強調手作的溫度與情感，用詞溫柔
   - 英文：簡潔有力，突出 handcrafted 和 cozy 的感覺
   - 日文：使用柔和可愛的表達，強調細節

4. **完成後**
   - 更新 data/project.ts
   - 複製圖片到 public/projects/
   - 詢問是否部署
```

## 💡 提示詞撰寫技巧

### ✅ 好的提示詞

- **具體明確**: 說清楚想要什麼風格、語氣
- **提供背景**: 上傳圖片並描述特殊之處
- **分步驟**: 讓 AI 知道完整流程
- **指定格式**: 要求 JSON 或特定結構

### ❌ 避免的提示詞

- **太模糊**: 「幫我寫個描述」
- **沒有方向**: 沒說明想要的風格
- **一次太多**: 混雜多個不相關的請求
